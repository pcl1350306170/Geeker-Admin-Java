## 附：实施说明与需求差异（2026-08-17 完成）

1. **接口前缀**：需求写 `/api/dev/assets`，实际定为 `/geeker/dev/assets`。原因：前端 vite 代理会剥离 `/api` 前缀，后端现有接口统一 `/geeker` 前缀，保持风格一致。
2. **created_by 存用户名**：现有 JWT 只存 username（无用户 ID），故 `created_by/updated_by` 设计为 VARCHAR(50) 存用户名，不改动现有认证体系。
3. **搜索方案**：未采用 MySQL FULLTEXT（中文需 ngram 解析器且依赖服务器配置），改用多关键词 LIKE 多字段匹配 + CASE WHEN 加权评分排序（title=4 > tags=3 > description=2 > content=1 / language=1），全部参数绑定防注入，天然支持中文子串与错误信息搜索。
4. **不单独设 /search 接口**：列表接口 keyword 非空即为搜索，前端首页大搜索框与列表页共用同一接口。
5. **菜单接入**：通过 `dev_asset.sql` 向 `sys_menu` 插入 7 条菜单（roles='admin,user'），前端动态路由零改动接入。
6. **新增依赖**：仅前端新增 md-editor-v3@6.5.6（Markdown 编辑/预览，内置代码高亮与复制按钮），属约束允许的编辑器类依赖。
7. **Ctrl+K 全局搜索快捷键**：按需求留 V1.1，首页已有提示文案。
8. **示例数据**：内置 3 条示例资产（CSS 多行省略 / Vue3 Sortable 方案 / ArkTS root node 踩坑），可直接用于验收搜索功能。
