# 个人开发资产库 V1.0 任务清单

> 依据《个人开发资产库 V1.0 开发需求说明.md》拆解，结合当前项目实际情况编写。
>
> 当前项目现状：
> - 后端：Spring Boot 3 + MyBatis-Plus + Spring Security + JWT，端口 8880，token 通过 `x-access-token` 请求头传递
> - 前端：Vue3 项目，位于 `D:\CODE\FontEnd\Geeker-Admin`（本工作区通过目录联接 `src/test/Geeker-Admin` 访问）
> - 数据库：MySQL，现有表为 `sys_user`、`sys_menu` 等，新表统一使用 `dev_asset` 前缀，互不影响
> - 后端现有代码风格：`controller / dto / vo / entity / mapper / service` 分包，`Result<T>` 统一返回，MyBatis-Plus `Page` 分页

## Phase 1：数据库设计（4 张表，统一 `dev_asset` 前缀）

- [ ] 1.1 编写建表 SQL 脚本（建议放 `src/main/resources/dev_asset.sql`）
- [ ] 1.2 `dev_asset` 主表：
  - `id`、`title`、`type`（CODE/SOLUTION/TROUBLESHOOTING/PROCEDURE/SNIPPET）
  - `description`（简介/摘要）、`content`（Markdown 正文，LONGTEXT）
  - `language`（代码语言，可空）、`tags`（第一版用 JSON 字符串存储）
  - `is_favorite`（0/1）、`usage_count`（复制次数）、`parent_id`（派生来源）
  - `created_by`、`created_at`、`updated_by`、`updated_at`、`deleted`（逻辑删除）
- [ ] 1.3 `dev_asset_tag` 标签表（第一版若用 JSON 存 tags，此表可暂缓，但建议预留设计）
- [ ] 1.4 `dev_asset_relation` 资产关联表（第一版仅做"相关资产"，可后置）
- [ ] 1.5 `dev_asset_usage` 使用记录表：`asset_id`、`action`（VIEW/COPY）、`created_at`
- [ ] 1.6 索引设计：
  - `title`、`description`、`content` 建全文索引（FULLTEXT，注意中文需 `ngram` 解析器）
  - `type`、`is_favorite`、`deleted`、`updated_at`、`usage_count` 建普通索引
- [ ] 1.7 在 MySQL 中执行脚本并验证表结构

## Phase 2：后端开发

### 2.1 实体与映射层

- [ ] 新建实体 `DevAsset`、`DevAssetUsage`（`entity` 包，`@TableName` + Lombok `@Data`，与 `SysUser` 风格一致）
- [ ] 新建 `DevAssetMapper`、`DevAssetUsageMapper`（`mapper` 包，继承 MyBatis-Plus `BaseMapper`）
- [ ] 如需自定义搜索 SQL（FULLTEXT / 多字段加权排序），编写 Mapper XML 或注解 SQL

### 2.2 DTO / VO

- [ ] `DevAssetQueryDTO`：keyword、type、tag、isFavorite、pageNum、pageSize
- [ ] `DevAssetSaveDTO`：新增/编辑入参（type、title、description、content、language、tags）
- [ ] `DevAssetListVO`：列表轻量返回（不含 content，满足性能要求：id/title/description/type/tags/language/usageCount/updatedAt/isFavorite）
- [ ] `DevAssetDetailVO`：详情完整返回（含 content、parent 信息、相关资产、使用记录）

### 2.3 Service（`DevAssetService`）

- [ ] 分页查询（按 type / tag / 收藏筛选）
- [ ] 全文搜索：覆盖 title、description、content、tags、language；第一版可用 MySQL FULLTEXT，多关键词拆分匹配；排序优先级：标题 > 标签 > 简介 > 正文
- [ ] 新增资产（写入 created_by）
- [ ] 编辑资产（自动更新 updated_at、updated_by）
- [ ] 逻辑删除（deleted 置位，删除前校验存在性）
- [ ] 收藏 / 取消收藏
- [ ] 复制记录：`usage_count + 1` + 写入 `dev_asset_usage`（action=COPY）
- [ ] 查看详情：记录 VIEW（可选），返回正文
- [ ] 基于旧资产创建（duplicate）：复制 title/type/language/tags/content/description，标题加" - 副本"，写入 parent_id
- [ ] 首页聚合数据：最近使用（10 条）、收藏、常用资产（按 usage_count）、最近更新

### 2.4 Controller（`DevAssetController`，路径 `/api/dev/assets`）

- [ ] `GET /api/dev/assets` 分页查询（keyword/type/tag/isFavorite/page/pageSize）
- [ ] `GET /api/dev/assets/search` 搜索
- [ ] `GET /api/dev/assets/{id}` 详情
- [ ] `POST /api/dev/assets` 新增
- [ ] `PUT /api/dev/assets/{id}` 修改
- [ ] `DELETE /api/dev/assets/{id}` 删除
- [ ] `PUT /api/dev/assets/{id}/favorite` 收藏/取消
- [ ] `POST /api/dev/assets/{id}/copy` 复制上报（usage_count+1 + 日志）
- [ ] `POST /api/dev/assets/{id}/duplicate` 基于旧资产创建
- [ ] `GET /api/dev/assets/home` 首页聚合（最近使用/收藏/常用/最近更新，可按需合并进列表接口）
- [ ] 返回值统一使用 `Result<T>`，分页结构与现有 `/geeker/user/list` 保持一致（list/total/pageNum/pageSize）

### 2.5 安全与配置

- [ ] `SecurityConfig` 中确保 `/api/dev/assets/**` 走 JWT 鉴权（与现有受保护接口一致，不额外放行）
- [ ] 从 JWT 中解析当前用户 ID，填充 created_by / updated_by
- [ ] 入参校验（标题非空、type 枚举合法、content 长度上限）
- [ ] 注意 SQL 注入（全部走 MyBatis-Plus 参数绑定，搜索关键词禁止字符串拼接）
